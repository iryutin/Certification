# Онлайн платформа-торговой сети электроники

Веб-приложение онлайн платформы-тороговй сети электроники с возможностью формирования цепи поставок товаров

## ✨ Возможности

- Создание сети поставок товаров
- В поставщеках указывается контактная информация уровень поставок и товар

## 🚀 Установка и запуск

### 1. Установка зависимостей

```bash
# Установка Poetry (если не установлен)
pip install poetry

# Установка зависимостей проекта
poetry install
```

### 2. Настройка базы данных

```bash
# Активация виртуального окружения
poetry shell

# Создание миграций
python manage.py makemigrations

# Применение миграций
python manage.py migrate
```

### 3. Запуск сервера

```bash
python manage.py runserver
```

После запуска откройте браузер и перейдите по адресу: http://127.0.0.1:8000/

## 🔌 API Endpoints

### Получить список всех сетевых узлов
```
GET /api/networknodes/
и др. методы
Поиск по стране
GET /api/networknodes/?search=<текст>
```

### Получить список всех продуктов
```
GET /api/products/
и др. методы
```

## 🗄️ Модели данных

### Contact (Контакт)
- `email` - Email
- `country` - Страна
- `city` - Город
- `street` - Улица
- `house_number` - Номер дома

### Product (Продукт)
- `name` - Название
- `model` - Модель
- `release_date` - Дата выхода на рынок

### NetworkNode (Звено сети)
- `name` - Название
- `node_type` - Модель
- `contact` - Дата выхода на рынок
- `products` - Продукты
- `supplier` - Поставщик
- `debt` - Задолженность перед поставщиком
- `created_at` - Время создания
- `level` - Уровень иерархии
